ClaudeStyle - your own background, fonts and Quick CSS for Claude
=================================================================

There are two versions. Try the app version first; if it can't connect,
use the browser version (most reliable).

APP VERSION (the normal Claude desktop app)
  1. Double-click "Install.bat".
  2. That's it - just open Claude the normal way. ClaudeStyle starts with
     Windows and connects by itself whenever Claude opens.
     (The "ClaudeStyle" Desktop shortcut also works, and opens Claude for you.)
  3. If a popup asks for one more click: in Claude open the menu
     (top-left, or press Alt) > Developer > Enable Main Process Debugger.
  4. Click the palette button in Claude's top-left toolbar (next to the
     back/forward arrows) or press Ctrl+Shift+Y.
  Quit Claude normally when you're done; ClaudeStyle stops by itself.

  Keep Developer > Enable Main Process Debugger ticked in Claude - that's
  the door ClaudeStyle uses to get in.

THE PANEL
  Themes    one-click looks (backdrop, glass panels, font and accent)
  Backdrop  your own image (drag & drop), 8 gradients, darken, blur, colour
  Style     panel colour, opacity, frosted glass, roundness, accent colour
  Text      10 built-in fonts, any font installed on your PC, code font
  More      Quick CSS, copy/paste themes, button position
            (toolbar / floating / hidden), reset (with Undo)
  Drag the panel by its title to move it; drag its bottom-right corner to resize.
  Double-click the panel title to put it back.

BROWSER VERSION (Claude in its own window via Edge/Brave/Chrome)
  1. Double-click "Install Browser Version.bat" and follow the popup
     (one-time: switch on Developer mode, Load unpacked, paste, Select Folder).
  2. Open "ClaudeStyle (Browser)" from your Desktop and sign in to Claude once.
  3. Click the palette button (bottom-right) or press Ctrl+Shift+Y.
  Right-click its taskbar icon > Pin to taskbar to keep it like an app.

IF SOMETHING GOES WRONG
  Run "Diagnose.bat" and send the report (it includes ClaudeStyle's log).

REMOVE
  Double-click "Uninstall.bat". Your normal Claude app is never changed.
